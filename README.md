# Laundry Mart Login Page

## Task
CSS Develop Laundry Mart Login Page using Flexbox.

## Description
This project is a simple and responsive Laundry Mart login page created using HTML and CSS.

The page contains:
- Laundry related image
- Email input field
- Password input field
- Forgot Password link
- Login button
- Register Now link

## Technologies Used
- HTML5
- CSS3
- Flexbox

## Features
- Clean login interface
- Split layout
- Flexbox alignment
- Responsive design
- Hover effect on login button
